Your agent says it's done.
charter checks.

Long-horizon agent tasks rarely fail loudly — they fail by declaring victory on deliverables that don't exist, don't pass, or were silently dropped. charter turns "done" into a machine-checkable contract, gates every agent run through a bounded verify→repair loop, and keeps a tamper-evident audit trail. Like CI, but for agent deliverables.

# try it in under a minute — zero dependencies, single file, stdlib-only Python ≥3.11
uvx --from git+https://github.com/zhenthebuilder/charter-gate charter --help

How it works

1 · Contract

Declare deliverables in charter.toml: paths and globs, size floors, required / forbidden patterns, freshness — plus arbitrary acceptance commands (exit 0 = pass).

2 · Gate

charter run -- <any agent command> runs your agent, verifies the contract, and on breach re-invokes the agent with the violation report injected. Bounded repairs, no infinite loops.

3 · Audit

Every attempt is appended to a hash-chained .charter/audit.jsonl with SHA-256 of each deliverable — prove what the agent produced, when, and detect tampering after the fact.

It works with any agent

If your agent is a shell command, charter can govern it — Claude Code, Codex, a Python script, a Makefile target:

charter init                       # scaffold charter.toml
charter verify                     # exit 0 iff the contract is satisfied
charter run --max-repairs 2 -- \
  claude -p "Do the task. Fix every violation in the report if one is injected."
charter log                        # tamper-evident audit trail

Measured, not vibes

We A/B-tested the charter gate on all 164 problems of HumanEval (official OpenAI scoring harness, hidden tests never shown to the model): same model, same prompt — the only difference is a deliverable contract with a verify→repair loop on the B arm. The honest headline: at 97.6% baseline accuracy the gate changed pass@1 insignificantly (98.2%, McNemar p=1.0) — but it caught 18/164 first-attempt contract breaches, auto-repaired 17, surfaced 1 as an explicit failure instead of a silent "done", and broke nothing, at 1.12× model calls. Full raw logs, scoring code, and a NeurIPS-style paper are in the repo's research companion.
