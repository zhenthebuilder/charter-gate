# Research companion: "Deliverable Contracts for Long-Horizon Agents"

- `paper/paper.pdf` — NeurIPS-preprint-style paper. Every number is generated by
  `experiments/analyze.py` into `paper/numbers.tex` from the raw logs below; nothing hand-typed.
- `experiments/runs/{A,B}/HumanEval_*/` — raw per-task artifacts for both arms
  (raw model outputs `call_n.txt`, solutions, smoke tests, charter audit chains).
- `experiments/runs/samples_*.jsonl{,_results.jsonl}` and `pass_at_1_*.json` — official
  OpenAI human-eval harness inputs/outputs (harness vendored under `experiments/vendor-human-eval`,
  with the README-documented execution line uncommented).
- Reproduce scoring: `python3 experiments/collect_and_score.py`; analysis: `python3 experiments/analyze.py`.

Headline (honest): pass@1 97.6% (A) vs 98.2% (B, charter-gated), 1 discordant pair,
exact McNemar p=1.0 — a null accuracy result at ceiling. The gate caught 18/164
first-attempt contract breaches (17 auto-repaired, 1 surfaced as explicit failure),
with 0 regressions, at 1.12x model calls.
